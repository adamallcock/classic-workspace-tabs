Frequently asked questions

Does it read my Workspace data?

No. The extension does not read page content, forms, messages, files, or events. It only updates favicon links in the document head.

Why do the icons look different?

The extension restores the familiar app-specific favicon set used before 2026, making different Workspace tabs easier to recognize.

Which pages are supported?

It uses an explicit list of supported Workspace URL patterns. The complete auditable list is available in the public manifest.

Is this an official Google extension?

No. This independent open-source project is not affiliated with, endorsed by, or sponsored by Google.
